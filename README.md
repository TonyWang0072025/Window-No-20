# 20号窗台 · Window No. 20

一个基于 ESP32 的桌面电子摆件：小猫在窗边生活，陪伴专注，收集星星，收藏生日小信。

## 核心体验

- **小猫陪伴**：在固定地点活动，夜晚更容易睡觉，无需喂养或强制照顾。
- **专注计时器**：15、20、30、45、60分钟；支持不限时暂停。
- **星星瓶**：完成15／20／30分钟获得1颗星，45分钟2颗，60分钟3颗。
- **昼夜窗景**：按 UTC+8 在06:00与18:00切换；晴朗、多云、小雨及稀有流星窗景。
- **生日秘密信箱**：首次欢迎仪式、可反复阅读的小信与动画回看。

当前版本无声；日常无操作10分钟调暗、累计60分钟熄屏，专注相关界面保持正常亮度。
