# 《20号窗台》 · Window No. 20

一件以 ESP32 为核心的小型桌面电子摆件：屏幕里有一间小屋、一只陪伴生活的猫、专注计时器、星星瓶、生日秘密信箱和可手动校时的挂钟。

> **项目状态（2026-11-11）**：第一轮原型开发中。串口、OLED显示及第一只按钮的基本按压验证通过。三键已接入P25/P26/P27，三键诊断程序编译、烧录及空闲状态检查通过，新增两键实际按压待反馈。当前接线见[固件指南](firmware/README.md)，证据见[开发验证记录](docs/development-log.md)。P0完整交互及P1–P3尚未验收；成品硬件、PCB、正式像素美术及电池续航尚未验证。

## 愿景

- 是可以放在书桌上、安静陪伴的艺术小摆件，而不是必须照顾、喂养或学习打卡的“任务宠物”。
- 礼物氛围温暖、轻童话感、朋友之间有趣而特别；方便异地邮寄，非专业使用者无需编程和网络配置。
- 一套送人，一套自留。另附一本彩色产品设定画册及名片尺寸的手写保修卡。
- 当前版本**完全无声**；小猫与专注奖励互不绑定，没有惩罚和功能解锁门槛。

## 核心组件

| 部分 | 已确认体验 |
| --- | --- |
| 小猫房间 | 简化方案C：左书桌、中央星星瓶、右窗台与右下猫窝、左上秘密信箱，以及朴素稍大的时钟 |
| 专注 | 15/20/30/45/60 分钟，完成奖励分别为 1/1/1/2/3 颗星；无限暂停、提前终止不奖励 |
| 星星瓶 | 累计只增不减，页面内查看数字；0空、1–25少、26–50中、51+满 |
| 秘密信箱 | 3–5 封从一开始全部可读的信；首次进入仪式动画；可从信箱重看生日欢迎动画 |
| 昼夜与天气 | 按设备自身的 UTC+8 24小时钟，06:00切白天、18:00切夜晚；天气每半天随机抽取 |
| 时钟 | 三键主动校准；完全断电后从12:00继续走，无须强制设置 |
| 断电存档 | 星星、首次生日动画及信箱首次动画记录必须跨换电池保留 |

## 已选定的实体方向（**未制造**）

- **屏幕**：横屏 2.42 英寸、128×64 白色单色 OLED，黑底白色发光点；参考 SSD1309 模块，具体采购型号/接口待核验。
- **主控**：当前普通 ESP32 套件用于验证；正式版优先 ESP32-C3-MINI-1＋定制 PCB。
- **供电**：优先 3 节 5 号（AA）碱性干电池；设计目标 **2–4 周、最好约 30 天**，尚未证明。
- **造型**：深色、厚实、可稳立的 3D 打印“小窗匣子”，屏幕后仰约 10°–15°，正面三键。
- **制造**：计划嘉立创 PCB 打样，优先评估 SMT 代贴；3D 打印外壳；制作赠送版和自留版各一套。
