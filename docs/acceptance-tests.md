## D. 工程特别风险

1. 连续暂停可无限长，屏幕按需求常亮，会显著影响电池寿命；应在测量时分别报告“一般日常”与“长期暂停”的场景，不能用最优条件夸大续航。
2. 写入Flash期间突然掉电可能使最近一次状态更新未成功持久化；通过读回、写入顺序/恢复策略和压力测试降低风险，**不夸大为绝对安全**。
3. 夜间流星动画、白天特殊天气档的具体规则尚未最终确认，不能为了“通过”凭空制定概率。
4. 0.96英寸原型不能替代2.42英寸真实显示面积、功耗与外壳测试。
5. 初次烧录/实际接线前检查**具体板型、供电电平和GPIO**，杜绝照抄不匹配接线图。
