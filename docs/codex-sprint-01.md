# Codex 第一轮原型开发交接任务书 — Sprint 01

准备日期：2026-11-03｜任务性质：**软件与基础硬件原型**｜**尚未开始执行，不代表任何任务通过**。

## 0. 任务目标和范围

用作者已拥有的**普通ESP32开发板＋入门套件0.96英寸单色OLED＋3个按钮**，做能编译、能烧录、可复现验证的最小可用原型。先验证核心状态与断电存档，再考虑正式屏幕、ESP32-C3、3AA电源、PCB和3D打印。

**最终屏幕仍是2.42英寸、横向128×64白色单色OLED；开发板0.96英寸OLED仅为初期证明。**

### 明确不在本轮范围

- 不采购屏幕/元件，不直接向嘉立创下PCB订单，不设计量产外壳或保证一个月续航；
- 不实现完整美术/猫动画/成品生日信文案，不通过联网配置时间，不增加音频、触摸屏或传感器；
- 不擅自定稿白天1%特殊天气、猫咪行为概率、深睡方案或未批准的交互细节；
- 不默认设备/板型/0.96英寸OLED/接线引脚：**先由作者拍照或按丝印确认**。

## 1. 首先做的检查

1. 阅读根目录 AGENTS.md、README 和 docs 内全部设计规范。
2. 确认仓库当前状态/是否已有固件；建立独立开发分支。
3. 列出作者套件实际板型、0.96英寸OLED的接口（如I²C、SPI）、分辨率与供电要求、按钮规格、USB数据线/电脑系统。**如果无实物照片、丝印或电路资料，先输出检查清单，不给无根据的具体GPIO接线。**
4. 选定一个可维护的编译工具链（Arduino-ESP32或ESP-IDF均可），说明版本、依赖、安装和烧录方法。优先用零编程背景的作者能执行的方案。
5. 软件设计上先使用**横向128×64虚拟画布**，实际显示驱动抽象隔离，便于未来改SSD1309/2.42英寸OLED和ESP32-C3。

## 2. 第一轮实现任务（建议顺序）

### P0：显示 + 三键输入最小回路

- 0.96英寸OLED能展示欢迎占位画面和黑白主房间线框，正确渲染中文字形或至少清晰占位；确认实际字库容量。
- 按键返回／切换／确认的去抖、单次触发、无高亮起始状态，以及“书桌→星星瓶→信箱→时钟”的循环选择。
- 可视化高亮（反白/描边均可），无高亮时返回/确认无操作。
- 通过串口打印状态和按键事件，方便无编程背景的作者验证。

### P1：专注计时核心状态机

- 时长五档与三键操作；使用单调时基而不是墙上24小时钟，以便任意时钟校准不影响专注。
- Running/Paused/ExitConfirm/Completed/Abandoned：完整进入、暂停恢复、提前结束确认、自然完成。
- Running画面显示中上部倒计时，Paused显示**纯黑底“暂停”**，Completed显示**纯黑底“专注完成”**，无房间叠图。
- 奖励逻辑 15/20/30/45/60 => 1/1/1/2/3；自然完成即记星并只发一次；未完成/提前退出无奖。
- 可以用“快速时间模式”做自动化测试，但**默认正式行为必须用真实分钟和秒**。

### P2：NVS持久记录

- 按规范持久化累计星星、首次生日欢迎完成记录、信箱首次仪式记录；分别存不同键。
- 启动时读取；完成专注写入并读回验证；重启（包括真断电）不丢。
- 模拟启动欢迎（首次仅一次、等确认）、信箱首次仪式与选信导航；不制作真实私人信件。
- 演示长时间完成页停留、重复刷新和重启不会重复发星。
- 请说明电源在Flash写入瞬间掉电的剩余风险，提出后续断电压力测试计划。

### P3：时钟/昼夜与基础闲置规则

- 完全断电启动时默认12:00、24小时制、无需强制校时；通过三键主动校时；保持设备本地时间走动。
- 按设备本地时间06:00与18:00切换日夜，未校准仍工作。
- 天气机制可先实现接口/占位画面与固定测试种子；原设计有80/10/9/1，但**白天特殊1%未确认，不能声称全逻辑完成**。
- 10分钟闲置低亮、累计60分钟熄屏（在实际硬件驱动支持时验证），熄屏首键仅唤醒；所有专注态（含暂停、退出确认、完成等待）不得自动调暗/熄屏。
- **本轮可以先只验证屏幕逻辑熄屏，不要求正式 ESP32-C3 深睡**。必须把未实现的硬件低功耗清晰标出。

4. 完全断电后星星、欢迎记录、信箱首次记录均保留；时钟按需求重新从12:00走。
