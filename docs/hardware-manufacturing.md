# 《20号窗台》硬件、电源、制造方案

版本 V0.2｜2026-11-03｜**目标规格，不代表实物测试通过**。

## 1. 硬件架构

~~~mermaid
flowchart TD
    AA[3节AA碱性干电池串联: 标称4.5V] --> SW[待选电源开关/反接保护]
    SW --> PM[高效率低待机损耗的3.3V电源管理]
    PM --> MCU[ESP32-C3-MINI-1 正式主控候选]
    PM --> OLED[2.42英寸 白色单色OLED 128x64]
    BTN[返回 / 切换 / 确认 3键] --> MCU
    MCU --> OLED
    MCU --> NVS[内置Flash/NVS: 星星/一次性标记]
    MCU --> CLK[设备计时/低功耗定时, 默认12:00]
~~~

- **已确认**：2.42英寸、128×64单色白色OLED；最终 ESP32-C3-MINI-1 模组＋小型定制PCB；三节 AA 碱性干电池为优先方案；嘉立创打样、3D打印外壳。
- **验证路径**：已有普通ESP32开发板＋0.96英寸单色OLED做第一轮软件交互验证；后续才采购正式屏幕、ESP32-C3和电源件并实测。
- **不允许**：把3节AA直接接到不明的ESP32“3.3V”端；把旧0.96寸OLED当作正式画面尺寸；未经验证声称已达30天续航。

## 2. 屏幕尺寸与接口

选定的显示方向是**物理2.42英寸OLED、128×64横屏、黑底白亮像素**，不是彩色TFT，也不是一大块离散LED点阵。

参考某微雪SSD1309屏幕版本：
- 显示区约 **55.01×27.49 mm**；
- 参考模块外形约 **61.5×39.5 mm**；
- 驱动与接口可能依具体SKU为 SSD1309 / SPI 或 I²C 等；正式采购前**按商品型号、规格书和实物接口复核**；
- 模块功耗依屏幕亮点数量及板载电路变化，有些模块全黑时也消耗毫安级电流，**不是全黑就零耗电**。

正式屏幕功耗、模组驱动/库、供电接口电压、亮度命令、物理可视角度均须在原型板上验证。

## 3. ESP32与低功耗

- 第一轮**普通ESP32开发板**，仅验证程序和最基本电路。开发板USB串口芯片、板载LED与稳压器耗电可能比最终主控大。
- 正式主控候选 **ESP32-C3-MINI-1**；可使用工厂贴片的小板优化面积和待机电流。
- 屏幕在正常闲置10分钟调暗，累计60分钟熄屏；应研究关显示/关OLED供电和主控休眠组合。**关OLED供电必须保证信号脚不会反向灌电流**，不应随意拉断供电。
- 三键可唤醒是产品底线；所有唤醒事件首次只唤醒，不作为游戏操作。进入/退出休眠后记录时间进度，保持06:00/18:00切换。
- 专注进行/暂停/退出确认/完成等待确认时**屏幕一直正常亮度**，无限暂停会持续用电，这对续航目标形成实际限制。续航取决于用户使用行为，不能保证每个人一个月。

## 4. AA供电的电气注意点

- 三节**串联**标称4.5V，电池随放电电压下降。三节串联并不意味着容量mAh乘三，电池组能量与电压及电池曲线相关。
- 目标主控稳定3.3V，电池组电压既可能高于也可能低于它，因此优先比较**低静态电流升降压(buck-boost)电源方案**，选型基于效率曲线/工作电流/峰值负载/低电压停机；还需考虑OLED模块自己的接口及电压需求。
- 需考虑电池极性、防反接、漏液/存放提示、电池更换便利性和螺丝小件安全；标注使用**相同类型、相近新旧程度的电池**，避免新旧混用。
- 外设、开关、电源转换器的休眠耗电都要进入整机预算。

### 续航预算：仅设计推算

例：以每节AA可用约2000mAh、标称1.5V作**粗略假设**，三节串联的初始名义能量约 3×1.5V×2Ah = 9Wh（未扣除电压曲线、负载、变换损耗、低温、自放电）。要用30天即720小时，平均输入功率上限约9Wh/720h = 12.5mW；再考虑转换损耗，输出侧平均功率必须更低。**这一预算不能替代实际电池放电和30天续航试验**。

需要分状态测电流：满亮房间、专注显示、调暗、熄屏、主控休眠、唤醒瞬间；按真实日均使用时长做加权估计。

## 5. 24小时制时钟

- 用户确认**不强制校时**，不用NTP/手机App，也不将独立带后备电池RTC作为第一版的必要配置。
- 完全断电重新上电，设备本地时钟**默认12:00**并自动继续；可经三键校准小时和分钟。
- 昼夜与天气始终按**设备时间**运行；未校准可与现实北京时间错位，属于产品允许的自定义体验。
- 正常供电、OLED熄屏、主控省电时，设备时间仍应向前；睡眠计时的漂移及是否引入32kHz晶振待测试。校准在12:00默认后随时可完成。
- 时间不要求跨**完全断电**继续准确走时；它与跨电池保留存档是两个独立问题。
- 时间调整不得使专注计时额外获得奖励；用单调计时实现专注。

## 6. 持久数据及掉电安全

**必须跨换电池保留**：累计星星数、首次生日欢迎完成记录、信箱首次仪式完成记录。建议使用 ESP32 内置 Flash 的 NVS/Preferences（或等价受测方案）；原型要验证独立字段、读回和重启一致性。

- 只在自然专注完成时给对应星星并持久写入；**同一次完成只记一次**，避免重复刷新/重启加星。
- 首次生日欢迎在产品定义的完成点存档，避免看完下次又自动出现；信箱仪式使用独立标记。
- 优先将一次奖励视作一个完整的、可验证的状态更新；Flash写入瞬间断电仍可能丢失最新更新，需设计可靠写入和故障恢复策略，并进行掉电压力测试。
- 修改固件和重烧程序时应避开会擦除 NVS 的操作，能否真正保留在升级后也需测试。
- 天气/设置/外观配置的跨断电策略可另定，不得影响三个核心存档。

## 7. 3D打印实体结构

- 外观选定：深色、厚实、有体积感、能稳立的 A2 **小窗匣子**；不是薄相框，**屏幕后倾10°–15°**；正面下方三键（左返回、中切换、右确认）。
- 根据真实2.42英寸OLED模组的**边框、PCB厚度、螺孔和排线出线**决定开窗与固定；有效发光区域约55×27.5mm不等于模块可安装外形。
- 电池仓背部或底部皆可；作者明确把位置推迟到实际结构与3D打印评估时再定。
- 规划内部：屏幕与正面面板、主控PCB、3节AA及电池触点、按钮、电源开关和调试/烧录接口、后盖或电池仓门、走线空间；间隙与固定方案待打样。
- 样机先打外壳空模/装配测试，检查桌面倾倒稳定性、查看角度、可换电池操作、线缆挤压与按钮手感，再冻结尺寸。
- 可先用FDM验证外壳几何，最终打印工艺和颜色由实际条件决定；不要先于真实硬件量尺寸。

## 8. 嘉立创 PCB 流程

~~~mermaid
flowchart LR
    P[原型功能通过] --> Q[主控/屏幕/电源实测]
    Q --> R[确认原理图与PCB布局]
    R --> S[核对嘉立创可用SMT元件/价格]
    S --> T[PCB打样与贴片]
    T --> U[焊接/屏幕按钮电池整机装配]
    U --> V[功耗/安全/存档/功能验收]
    V -->|未通过| Q
~~~

嘉立创PCB制作不自动等于SMT贴片完成；应分别确认物料清单(BOM)、贴片坐标、器件库存与成本。两套设备可用同一版PCB，制造前需核对最小订购数量与工厂实际要求。

## 9. 需要实测而非脑补的工程问题

- 2.42英寸模块的SKU/引脚/驱动供电以及ESP32-C3可用GPIO、按钮硬件去抖；
- 低功耗电源调节电路、整机状态耗电与典型电池曲线；
- 睡眠唤醒任意三键的可靠性、时间推进、时钟漂移；
- NVS异常断电后的恢复/重复奖励；
- 电池仓位置、装配公差、外壳倾角的稳定性；
- 专注过程中关屏超时被禁止的真实功耗代价。
