# 《20号窗台》视觉、美术和随礼画册

版本 V0.2｜2026-11-03｜性质：**艺术方向已获认可，正式素材尚未制作**。

## 1. 屏幕美术语言

最终电子屏幕为**2.42英寸，128×64横向，白色单色OLED**：黑底，只有图形及文字亮起。用户已明确认可这种像素感和高对比效果；不做彩色显示屏，不强求把橘猫颜色/白胸口在1-bit屏幕表达出来。

**2026-11-11原型视觉反馈：作者明确认为当前P0屏幕图案很丑，要求后续必须修改。**
当前程序中的房间、猫和物件只是导航功能验证用线框占位，**不得作为成品美术交付或判定视觉验收通过**。
后续必须按本文件已经批准的方向重新制作128×64单色像素素材，并单独提交作者审阅和实机验证。
这条反馈不改变黑底白色单色、自然圆脸小猫及既定房间构图，也不代表已经选定新的美术细节。
0.96英寸仍只是原型测试屏，最终屏幕仍按2.42英寸白色OLED方向验证。

此前彩色像素场景**方案C**仅作为构图参考。不能直接将高分辨率彩色图片机械缩放、转灰或把“非白色关闭”就假设可辨认；应基于128×64用手工或工具优化轮廓和最小笔画，遵守字形/像素格网。

## 2. 房间构图元素

- **左侧**：书桌与摊开的书，专注时猫到此低头看书。
- **中央**：小台上的星星瓶（进入详情才显示准确累计数）。
- **右上**：窗户，可显示白天/黑夜、晴/云/细雨/稀有流星。
- **右下**：软垫/猫窝，平常猫咪可蜷卧休息。
- **左上**：低调秘密信箱；无通知小红点。
- 墙面：替换原装饰画为**略大、朴素的24小时制电子小时钟**，不添加钟周围装饰。
- 主房间尽量不放多余文字。功能选中时仅少量发光描边/提示，避免密集覆盖。

示意的推荐信息层级（非像素坐标定稿）：

~~~text
+--------------------------------------------------------------+
| 邮箱       朴素时钟                        窗户              |
|                                                              |
|         【专注时：倒计时居中偏上，优先可读】                  |
| 书桌/猫                星星瓶             窗台                |
|                                              猫窝            |
+--------------------------------------------------------------+
128 × 64 像素，横向；所有图形比例需实机验证
~~~

## 3. 角色设定

- 名字尚未定，完整美术为**橘猫、圆脸、微胖、白胸口**；毛发维持目前简约自然效果，不增加刻意长毛尾巴或别的花纹特征。
- 黑白屏的角色设计只须有**可爱、可辨认的基本轮廓**；原色与角色档案在彩色画册中呈现。
- 不拟人：不穿衣、不持书、自然猫咪坐姿，前爪搭在书桌上，低头看打开的书。
- 常态：猫窝休息/睡、窗台看窗外；主要靠固定地点间走动、在窗右侧固定点上下跳，节约帧数。
- 专注：到书桌，翻书动作适度；自然完成时伸懒腰。
- 第一版**不制作眨眼、清洁毛发/舔毛**；不需要复杂的物理模拟、自由寻路或不断播放动作。

## 4. 屏幕页面视觉

| 页面 | 已确认表现 |
| --- | --- |
| 普通房间 | 黑底白亮点的室内场景，小猫行为与窗景持续运行 |
| 选择专注时长 | 独立简单界面，预设大数字，无“WINDOW NO.20” |
| 专注进行 | 房间仍可见，小猫书桌看书，数字在**画面正中偏上** |
| 暂停 | **纯黑背景＋“暂停”**，不显示房间 |
| 提前结束确认 | 清楚、克制、避免误操作；最终文字待定 |
| 专注完成 | **纯黑背景＋“专注完成”**，不显示房间 |
| 星星瓶 | **独立纯黑背景**，不显示后面的房间场景；瓶子放大＋真实累计数量 |
| 信箱选信/阅读 | 独立黑底页面，清晰信封/短文字，首次有轻仪式动画 |
| 时钟 | 房间内素净、略大的时钟；进入后24小时制查看/校时 |

**黑底不是彩色界面的“黑色背景图”**：对应OLED不发光像素，符合选定的单色显示风格。过高的发光像素密度可能增加耗电，应纳入测试。

## 5. 外壳与实物审美

- 用户确认**A2小窗匣子**：正面像小窗/相框，但整机是完整厚实小盒子，可稳定立桌面而非薄片。
- **深色系**防显脏；深棕/深灰蓝/深墨绿曾提出但没有锁定具体主色。避免把示意配色认作定稿。
- 屏幕向后倾斜**10°–15°**；正面底部三键：返回、切换、确认。
- 3D打印制造；可更换AA电池，仓位在背部或底部待实物结构决定；具体壁厚、尺寸、底座未锁定。

## 6. 产品设定画册（与屏幕美术并行的**彩色**成果）

产品背景是轻童话，**不大篇幅解释世界的来历**；小屋中有一只温和的橘猫、能看到天色和天气的窗、一只收集专注时光的瓶子、为新主人留下小信的信箱。不是复杂剧情游戏。

画册预计约**8–12页**（此前提供12页结构作为已认可的规划方向；最终页数/印刷规格待定）。建议内容：封面、作品简介和设计缘由、小屋短故事、小猫性格/档案、彩色三视图及状态图、房间与主要物件设定、昼夜天气原画、设计手记、简短生日寄语与封底。

**勿公开编造或写入私密的实际生日信件正文**。画册完成时可展示屏幕黑白像素形象与完整彩色角色稿的对照，让两种视觉表达形成完整艺术体验。

## 7. 独立随礼保修卡

- **名片大小、手写**；可做成有趣但不油腻的轻松保修卡，留下未来可维修和更新的想象。
- 内容、字体、实体包装与实际承诺由作者最终决定；不随意承诺永久维护或新增功能。
- 最终物品三件：主机＋设定画册＋手写卡；共制作设备两套。
