# 《20号窗台》待决事项与风险清单

更新至2026-11-03。本清单仅记录**未确认、未实测或可能影响开发**的问题；已被后续用户决策解决的旧问不继续列为待定。确认的规则请看[设计基线](design-baseline.md)。

| 优先级 | 问题 | 当前边界 / 临时处理 |

| 中 | 专注完成页是否显示“+N星”？ | 主文案“专注完成”与纯黑背景已确认，额外奖励文字尚未最后确认。 |
| 中 | 唤醒仅在完全熄屏时消耗首次按键；仅调暗时首次按键怎么办？ | 已确认熄屏首次只唤醒，调暗第一按键按普通按键处理还是只提亮待定。 |

| 中 | 时钟校准最小UI具体怎么排？ | 三键24小时制小时/分钟已确认；逐位设置是可用建议；具体交互可做样机后审。 |
| 中 | 退出确认提示、信件阅读长时间闲置、欢迎流程中断标志的准确写入时机 | 需先原型验证，保证不误终止、不反复播放、不篡改存档。 |

## C. 已从2026-11-01旧清单关闭的事项

- 三个按钮顺序、主界面循环、退出确认的大部分规则已从后续对话确定。
- 屏幕类别/正式分辨率由“待定”改为**2.42英寸128×64单色白色OLED**。
- 时钟不再是待选NTP或强制校时：**默认12:00自行走、三键可主动校准、未校准功能正常**。
- 外壳风格已选定深色小窗匣子、后仰10°–15°；电池选3节AA优先。
- 小猫不再计划眨眼/舔毛，毛色等彩色细节在随礼画册表现。
- 数据底线明确：星星、欢迎及信箱首次记录必须跨换电池保留。
- 六阶段/第一轮原型开发方向已经明确；正式成品与美术制作尚未开始。
